# Smart Industrial Monitoring System

## Overview
This project is an IoT-based Smart Industrial Monitoring System designed to monitor industrial parameters such as temperature, humidity, gas leakage, and vibration in real time using sensors and microcontrollers like Arduino/ESP32.

The system helps improve industrial safety, automation, and real-time monitoring.

---

## Features
- Real-time sensor monitoring
- Temperature and humidity detection
- Gas leakage monitoring
- Vibration/fault detection
- LCD/OLED display output
- IoT dashboard integration
- Alert and buzzer system

---

## Components Used
- ESP32 / Arduino
- DHT11 Sensor
- Gas Sensor (MQ2)
- Vibration Sensor
- LCD Display
- Buzzer
- Jumper Wires
- Breadboard
